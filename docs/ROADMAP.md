# Дорожная карта

Принцип: сначала доказать, что ядро «тайные приказы + AP + одновременное разрешение» интересно, потом наращивать
системы и людей. Всё, что требует решения владельца, помечено → [OWNER-QUESTIONS](OWNER-QUESTIONS.md).

## Сделано (M0, 2026-10-10)

- Репозиторий, ГДД v0.1 без правок, ADR 0001/0002, разбор узких мест и массовости.
- Решения владельца: бумажно-тетрадный 2D-стиль, нет стеков, FFA на 4 с первого дня, **непрерывное пространство как в
  Lines of Battle**, приказы группе ([04](analysis/04-grid-and-paper-style.md)).
- `packages/sim` (непрерывное пространство): разрешение хода по тикам, расталкивание тел, твёрдые стены, групповые приказы,
  три режима времени залпа, лог событий, туман. 34 теста, бенчмарк 4–64 игрока ([результаты](analysis/03-spike-results.md)).
- Клеточная версия сохранена тегом `spike-grid-v1` (36 тестов), для сравнения.

## Решения владельца, определяющие порядок (2026-10-10)

Онлайн, минута на ход (настраивается), четыре типа победы, «важно всё из ГДД». Стадии S1–S6 с обоснованием — в
[05](analysis/05-victory-scope-and-live-play.md) §5: S1 бой (hotseat) → S2 онлайн 1v1/FFA4 с ботами → S3 экономика, энергия,
дороги, очереди → S4 исследования → S5 шпионаж и глубина тумана → S6 баланс самоигрой, рейтинг.
