# CardboardRTS (рабочее имя)

Веб-игра: пошаговая тактика с одновременным исполнением тайных приказов (STBS). Каждый ход игроки тайно тратят очки
действий (AP) на приказы юнитам, затем сервер одновременно разрешает ход. Туман войны, экономика, инфраструктура,
шпионаж. Название на согласовании: [OWNER-QUESTIONS](docs/OWNER-QUESTIONS.md).

Статус: **проработка**. Есть ГДД v0.1, выбор стека, разбор узких мест и массовости, и спайк ядра правил с тестами.
Клиента и сервера пока нет.

## Запуск

Нужен Node 24+.

```bash
npm install
npm test          # 36 тестов ядра + 4 теста клиента
npm run dev        # прототип рендера, http://127.0.0.1:5173
npm run typecheck # tsc --noEmit
npm run bench     # замер 4 / 16 / 32 / 64 игроков
```

## Структура

```
docs/            ГДД, анализ, ADR, вопросы, дорожная карта
packages/sim/    чистое ядро правил: разрешение хода в непрерывном пространстве, расталкивание тел, туман (без IO и случайности)
  src/           types, geom, collide, resolve, fog
  test/          Vitest
  bench/         замер производительности
packages/client/ прототип на Phaser 4: тетрадный лист, рисование приказов, туман, проигрывание хода
```

Ядро (`@cardboard/sim`) намеренно не знает ни о рендере, ни о сети: его будут использовать и сервер, и клиент (превью
приказов), и боты, и тесты.
